# ✿ Becoming Her

### Little habits. A whole new me.

**Becoming Her** is a personal habit-tracking web application designed to help you build consistency, create healthier routines, and make progress toward your goals — one day at a time.

With a soft burgundy and blush-pink aesthetic, the application combines daily habit tracking, monthly progress insights, customizable schedules, and personal routine checklists in one place.

---

## ✨ Features

- **📊 Dashboard** — View your daily progress, habit completion, and consistency at a glance.
- **✅ Daily Habit Tracker** — Track eight habits, including career study, sleep, skincare, hair care, exercise, meals, reading, and walking.
- **📅 Monthly Progress** — Review your progress through monthly statistics, charts, and a calendar view.
- **🔥 Consistency Tracking** — Monitor your activity and build sustainable habits over time.
- **⏰ Personal-Day Boundary** — Customize when your personal day begins, particularly useful for late or night shifts.
- **💼 Work Schedule Management** — Configure work schedules to suit your routine.
- **🧴 Skincare Checklist** — Maintain personalized morning and evening skincare steps.
- **🌸 Weekly Hair-Care Planner** — Organize your hair-care routine by weekday.
- **💾 Backup & Restore** — Export your records as JSON and restore them later.
- **📱 Responsive Design** — Use the application across desktop and mobile screens.
- **🔒 Local Data Storage** — Save your records in your browser using `localStorage`.

## 🚀 Getting Started

### Option 1: Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/becoming-her-habit-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd becoming-her-habit-tracker
   ```

3. Open `index.html` in your browser.

For a smoother development experience, you can use the **Live Server** extension in Visual Studio Code.

### Option 2: Deploy with GitHub Pages

1. Push your project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under the build and deployment section, select **Deploy from a branch**.
5. Select your `main` branch and the `/ (root)` folder.
6. Save and wait for GitHub Pages to publish your website.

Your website URL will typically follow this format:

```text
https://YOUR-USERNAME.github.io/becoming-her-habit-tracker/
```

Replace `YOUR-USERNAME` with your GitHub username.

## 📖 How to Use

1. Open the Dashboard to review your daily progress.
2. Navigate to Daily Tracker to record your habits.
3. Visit Monthly Progress to explore your calendar and statistics.
4. Open Settings to personalize your day boundary, work schedules, and routines.
5. Export a JSON backup periodically to protect your records.

## 💾 Data & Privacy

Becoming Her stores habit records in the browser's local storage.

- Your records are stored locally in the browser where you use the application.
- Records do not automatically synchronize across browsers or devices.
- Clearing browser storage may erase your records.
- Use the JSON backup feature to export and restore your data.

**Important:** Browser-local storage is not a substitute for encrypted cloud backup. Avoid storing sensitive personal information in the application.
